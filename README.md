# gaugexml

Gauge filesystem xml paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/gaugexml/

## Install / run

```bash
git clone https://github.com/theworker02/gaugexml.git
cd gaugexml
node src/cli.js
node --test
```
